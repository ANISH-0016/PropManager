# PropManager
Commercial Real Estate Tenant Portal &amp; Automated Maintenance Dispatch System

## What it does

- Tenants can report maintenance problems.
- Maintenance requests can be tracked.
- Requests are assigned to technicians based on the type of problem.
- Managers can view and manage all requests.

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
